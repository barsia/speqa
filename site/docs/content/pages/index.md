Welcome to SpeQA - a powerful plugin for writing, organizing, and running test cases directly in your JetBrains IDE.

## What is SpeQA?

SpeQA brings test case management and execution into your IDE with:

- **Live Markdown editor** for test cases with interactive preview
- **Visual test run tracking** - mark steps as Passed, Failed, or Skipped
- **Built-in attachments** - add screenshots and files to test evidence
- **Claude Code skill generation** - automatically generate test case writing skills
- **Git-friendly** - store test cases as `.tc.md` files, just like your code

## Quick Path: 5 Minutes to Your First Test

1. [Install SpeQA](./installation.md) from the JetBrains Marketplace (click **Get** directly from plugin page)
2. [Create a test case project](./creating-project.md) using the wizard
3. [Write your first test case](./writing-test-cases.md) in the split editor
4. [Run the test](./running-tests.md) and track results
5. *(Optional)* [Generate a Claude Code skill](./claude-code-skills.md) to write test cases faster

## Key Concepts

**Test Case (`.tc.md`)** - A Markdown file describing what to test, how, and what should happen.

**Test Run (`.tr.md`)** - A record of executing a test case with results for each step.

**Claude Code Skill** - An AI skill that helps you write test cases faster (optional automation).
